# Wisp

Легкий Android-клиент для управления VPN-подписками. Автоматически загружает конфигурационные ссылки, обходит базовые блокировки через встроенный прокси и извлекает готовые `vless://` / `trojan://` ссылки в буфер обмена.

> ⚠️ **Важно:** Приложение не является VPN-клиентом и не подключается к серверам напрямую. Оно выступает как менеджер и парсер подписок для последующего импорта в сторонние клиенты (Happ и т.д.).

## ✨ Возможности
- 📋 Добавление, редактирование и удаление ссылок на подписки
- 🌐 Загрузка через WebView с автоматическим обходом через Yandex Translate
- 🔍 Парсинг HTML и извлечение всех `vless://` / `trojan://` ссылок
- 💾 Автосохранение состояния, даты обновления и кэша конфигов
- 🎨 Поддержка светлой, темной и системной темы
- 🔄 Встроенный менеджер автообновлений (проверка GitHub Releases, загрузка с прогрессом, установка APK)
- 🔒 Безопасность: отключён доступ WebView к файловой системе и контенту

## 📦 Установка
1. Перейдите в раздел [Releases](https://github.com/MrCECECE/Wisp/releases)
2. Скачайте последний `Wisp.apk`
3. Установите файл на устройство (разрешите установку из неизвестных источников, если потребуется)
4. Запустите приложение,нажмите `Обновить` → `Сохранить страницу`

## 🛠 Технологии

- **Сеть:** WebView
- **UI:** View-система
